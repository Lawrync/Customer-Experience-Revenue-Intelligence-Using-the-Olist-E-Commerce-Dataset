# Customer-Experience-Revenue-Intelligence-Using-the-Olist-E-Commerce-Dataset

# Overview.
This dataset is based on Brazilian Ecommerce transaction. The dataset contains 100000 orders made at olist store from 2016 to 2018 across multiple market places in Brazil. The dataset was extracted from https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce comprising of different CSV files.
